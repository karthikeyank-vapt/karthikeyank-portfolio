01 · Executive Summary

How I approach the work

I'm an MCA graduate (2024–2026) who tests web applications and APIs the way an attacker would — manually, methodically, and OWASP Top 10-driven — rather than relying on scanners alone. My focus is Web Application Penetration Testing, API Security Testing, and Vulnerability Assessment (VAPT), sharpened through independent bug bounty research and responsible disclosure.

Daily tools: Burp Suite, Nmap, Wireshark, Metasploit, Kali Linux — plus Python for automating reconnaissance. Looking for an entry-level role in Cyber Security, Application Security, or Penetration Testing where I can go deeper alongside an experienced team.

In Plain English

I find the security gaps in websites and apps before real attackers do — then help fix them, with a clear report anyone on the team can act on.

02 · Methodology

Recon to report

A repeatable seven-stage process, run the same way on every engagement.

01

Reconnaissance & Information Gathering

Identifying the attack surface through OSINT, subdomain enumeration, technology fingerprinting, and asset discovery.

02

Enumeration & Mapping

Mapping endpoints, parameters, APIs, authentication workflows, and application functionality.

03

Authentication & Authorization Testing

Evaluating login mechanisms, session management, access control, privilege escalation, and business logic.

04

Vulnerability Assessment

Identifying vulnerabilities including XSS, SQL Injection, IDOR, SSRF, CSRF, XXE, SSTI, File Upload, and OWASP Top 10 security risks.

XSSSQL InjectionIDOR SSRFCSRFXXE SSTIFile Upload
05

Manual Exploitation & Validation

Validating identified vulnerabilities manually, developing proof-of-concept exploits, and confirming real-world impact.

06

Risk Assessment & CVSS Scoring

Assessing severity, business impact, exploitability, and prioritizing findings using CVSS.

07

Reporting & Responsible Disclosure

Preparing detailed technical reports with remediation guidance, proof of concept, and responsible disclosure of verified security issues.
